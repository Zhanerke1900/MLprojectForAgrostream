# Field Forecast

Веб-приложение для агрономического прогноза урожайности по карточке поля.

Текущая версия проекта работает в одном сценарии и больше не использует старую Python/ML-модель. Прогноз строится по данным карточки поля и сезонным показателям, которые вводит агроном.

## Данные сценария

- Культура: `Пшеница мягкая яровая`
- Сорт: `Нерда`
- Репродукция: `Первая`
- Предшественник: `Лён`
- Площадь: `291.2 га`
- Посев: `19.05.2025 - 20.05.2025`
- Уборка: `20.09.2025 - 21.09.2025`
- Карта урожайности: `2025`

Пользователь вводит только:

- `СЭТ`
- `осадки за вегетацию`
- `гумус` при наличии данных

## Запуск локально

```powershell
npm install -g pnpm
pnpm install
pnpm.cmd dev
```

Если PowerShell блокирует `pnpm`, используйте:

```powershell
npm run dev
```

После запуска приложение доступно по адресу:

`http://localhost:3000`

## Как работает прогноз

1. Фронтенд показывает фиксированную карточку поля.
2. Агроном вводит сезонные показатели.
3. Запрос уходит в `POST /api/agronomic-predict`.
4. Сервер формирует:
   - диапазон урожайности `min/max`
   - средний прогноз
   - уровень достоверности
   - краткое агрономическое заключение
   - факторы влияния

Основная серверная логика находится в:

- `server/agronomicYieldForecast.ts`
- `server/_core/index.ts`

Основные страницы:

- `client/src/pages/Home.tsx`
- `client/src/pages/Forecast.tsx`
- `client/src/pages/About.tsx`
- `client/src/pages/Contact.tsx`

## Важно

- В текущем приложении больше нет рабочего контура старой ML-модели.
- Деплой и локальный запуск теперь не требуют Python-сервиса.
- Если в сезонных данных есть пропуски или значения выходят за рабочий диапазон, сервис может показать `низкую достоверность`. Это не ошибка, а честный сигнал о повышенной неопределённости прогноза.
